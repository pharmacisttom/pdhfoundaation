# Roadmap ระบบมูลนิธิ

อัปเดตล่าสุด: 2026-09-03

## พร้อมใช้งาน/มีฐานแล้ว

- Dashboard ผู้บริหาร
- ข้อมูลมูลนิธิ
- ผู้บริจาคและรายการรับบริจาค
- ใบเสร็จรับเงิน
- กองทุน โครงการ และรายการเบิกจ่าย
- บัญชีธนาคาร
- ครุภัณฑ์ เอกสาร ประชุม
- CMS ข่าว กิจกรรม แบนเนอร์ และหน้าคงที่

## ควรทำต่อเป็นลำดับแรก

1. ระบบผู้ใช้, สิทธิ์, และอนุมัติหลายระดับ
2. หน้า public สำหรับรับบริจาค, ข่าว, โครงการ, ตรวจสอบใบเสร็จ
3. รายงานการเงิน, donor history, และ export Excel/PDF
4. ระบบแจ้งเตือนงานค้าง เช่น อนุมัติค่าใช้จ่ายหรือเอกสาร
5. hardening สำหรับ production เช่น backup, log, error handling, upload policy

## ฟีเจอร์หลังบ้านที่มูลนิธิควรมี

- จัดการผู้บริจาครายบุคคล/นิติบุคคล
- ประวัติการบริจาคย้อนหลังและ thank-you workflow
- แยกกองทุนและโครงการแบบตรวจสอบย้อนหลังได้
- บริหารบัญชีธนาคารและ QR รับบริจาค
- ทะเบียนทรัพย์สิน/ครุภัณฑ์ที่จัดซื้อจากเงินมูลนิธิ
- สารบรรณและเอกสารการประชุม
- จัดการข่าวสาร ภาพกิจกรรม และไฟล์ดาวน์โหลด
- รายงานสรุปรายวัน/รายเดือน/รายปี

## แนวทางเฟสถัดไป

- Phase A: deploy production และเก็บ feedback จากเจ้าหน้าที่
- Phase B: ปรับ workflow งานจริงตามหน่วยงานการเงิน/ธุรการ
- Phase C: เปิด public donation และ dashboard โปร่งใส
- Phase D: เชื่อม SMS/Email แจ้งเตือนและระบบภาษี/ใบเสร็จเต็มรูปแบบ
